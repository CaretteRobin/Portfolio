# Crydo — masters visuels

Les fichiers de `final/` sont les captures maîtres issues du produit réel. Ils ne doivent pas être redimensionnés ni remplacés par des exports compressés.

## Captures desktop

- `crydo-observatory-desktop.png` : vue globale de l’Observatory.
- `crydo-btc.png` : BTC sélectionné dans l’Observatory.
- `crydo-eth.png` : ETH sélectionné dans l’Observatory.
- `crydo-sol.png` : SOL sélectionné dans l’Observatory.
- `crydo-analysis-desktop-courbe.png` : analyse détaillée et courbe d’évolution.

## Captures mobile

- `crydo-observatory-mobile.png` : Observatory mobile.
- `crydo-analysis-mobile.png` : analyse détaillée mobile.

Les dérivés destinés aux previews et aux partages sont générés dans `public/` par `scripts/generate-project-derivatives.mjs`.
