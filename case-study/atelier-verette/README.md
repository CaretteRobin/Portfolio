# Atelier Verette — case study

Source éditoriale et visuelle du projet réel Atelier Verette pour le portfolio de Robin Carette.

## Organisation

- `content.ts` : faits et textes réutilisables.
- `metadata.ts` : métadonnées de la page portfolio.
- `AtelierVeretteCaseStudy.tsx` : composition du case study.
- `case-study.module.css` : styles isolés et responsive.
- `assets/` : sélection de photographies finales et source OG existante.
- `screenshots/` : captures finales du case study.
- `notes/verification.md` : traçabilité des affirmations retenues ou omises.

La page est intégrée à la route existante `/projets/[slug]`. Le contenu et les assets spécifiques restent dans ce dossier.
